## Decisiones tomadas
- **Sync sheet**: el cron `sync-sheet.yml` falla porque la hoja de Google fue reemplazada por un aviso de migración (ya no tiene datos). Diagnosticado y explicado al usuario; **decisión de qué hacer con el cron quedó sin cerrar** (el usuario pidió el link del Excel y no volvió al tema).
- **Dominio propio**: `pegaungrito.com` (Cloudflare) reemplaza el subpath `juanfeds.com/voluntariado/` como dominio principal del proyecto. DNS apex vía A/AAAA a IPs de GitHub Pages, `www` sin CNAME a propósito (se prefirió dejarlo sin resolver antes que exponer `github.io`; luego se resolvió el warning de Cloudflare con una Page Rule de redirect `www→apex`, no con CNAME). `vite.config.ts` cambiado a `base: "/"` fijo.
- **Panel de administración**: acceso vía Supabase Auth (email/password), con `app_metadata.is_admin = true` fijado solo desde el servidor (SQL) — nunca por el propio usuario. Varios moderadores posibles (no un solo admin fijo). Alcance: moderación (aprobar/rechazar/eliminar/editar) + panel de métricas.
- **Ubicación de damnificados**: se generaliza a departamento (público) + municipio (público) + barrio/vereda (privado) + alcaldía más cercana (privada) — antes solo había "localidad aproximada". Justificación: la app ya no es solo-Bogotá.
- **Mapa de zonas afectadas**: burbujas agregadas por municipio (no puntos individuales, por privacidad), geocodificadas server-side vía cron nuevo (`geocode-municipios.yml`, cada 6h) — mismo patrón que ya existía para la hoja.
- **Rediseño visual v1 (rechazado)**: paleta fría + Overpass + tarjetas redondeadas + sombras suaves + beacon pulsante. El usuario lo rechazó explícitamente: "no me gusta, busca inspiraciones en la web".
- **Rediseño visual v2 (aprobado, pendiente de commit)**: investigación previa mostró que las galerías de diseño curado no sirvieron, pero las convenciones reales de sistemas de emergencia sí (triage START con etiqueta+color, NOAA por profundidad de color, tipografía plana de EAS/CAD de despacho). Nuevo marco: "bitácora de despacho duplicada" — JetBrains Mono como voz tipográfica dominante (se eliminó Overpass/Big Shoulders Display), colores de estado sólidos (no pastel), bordes duros sin radio, sombra offset dura al hover (efecto copia al carbón), perforación troquelada + código de campo numerado (`№ 001`) en cada tarjeta reemplazando el beacon. Verificado visualmente, sin errores — el usuario no ha confirmado el commit todavía.
- **Ramas**: `feature/admin-panel` ya se mergeó a `main` (fast-forward) y se pusheó — está en producción en `pegaungrito.com`. `feature/design-refresh-2026` se actualizó con el merge de `main` y contiene el rediseño v1 (obsoleto, sobrescrito localmente por v2 sin commitear).
- **juanfeds.com/develop**: el usuario pidió un "apuntador a develop" en `juanfeds.com/` mientras `main` sigue yendo a `pegaungrito.com`. Se le explicó que GitHub Pages solo permite un dominio por repo (no puede sumar esto sin un mecanismo nuevo: publicar cruzado al otro repo de portafolio, o Cloudflare Pages). **El usuario decidió no avanzar con esto por ahora** ("sigamos como estamos").
